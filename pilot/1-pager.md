# Shimmer, pilote pour boutique en ligne

## Ce qu'on installe sur votre boutique

Un vendeur IA qui répond aux visiteurs dans le ton de votre marque, un SAV qui prend en main les réclamations par mail, et des relances de paniers abandonnés. Tout passe par un seul dashboard, vos données ne quittent pas la France.

Concrètement vous gagnez :
- Les questions clients traitées 24h/24 sans embaucher
- Les paniers oubliés relancés avec un message qui ressemble à vous, pas à un robot
- Les 1-2 étoiles interceptés avant Google
- Le CA additionnel mesuré à l'euro près, pas estimé

## Ce qu'on demande pour le pilote

- 30 minutes pour brancher (catalogue + 3 lignes de code sur les fiches)
- Une semaine d'observation silencieuse (le vendeur regarde, ne parle pas)
- Une demi-journée pour valider ensemble les premières réponses
- Six semaines en live, on regarde les chiffres ensemble

## Ce qu'on garantit

- Le premier mois est offert : vous ne payez rien tant que le vendeur apprend et que vous n'avez pas validé ses réponses vous-même
- Ensuite, l'abonnement couvre ce qui tourne dès la deuxième semaine (SAV, avis, relances) ; la part variable, elle, ne porte que sur le CA additionnel mesuré contre un groupe témoin, sur vos propres commandes, vérifiable par vous
- Code et données sur serveur français, RGPD aligné
- Sans engagement : vous arrêtez quand vous voulez, tout se désinstalle en retirant une ligne de code

## Le bon profil pour ce pilote

- E-commerce mono-vendeur ou petite équipe
- Catalogue entre 30 et 1500 références
- 200 à 5000 visiteurs uniques par mois
- Vous lisez et répondez à vos mails clients vous-même

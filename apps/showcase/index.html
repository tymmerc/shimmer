Module 01

Le pipeline de recherche.

01

BM25 Lexical

<10ms

Index inverse, stopwords FR/EN, scoring TF-IDF. Matchs exacts sur noms, SKU, marques.

search("aspirateur robot") → [Roomba i7, Dyson V15, ...]
02

Embeddings

<100ms

Vecteurs 768D via multilingual-e5-base ONNX. Recherche par sens, pas par mots. Index HNSW + cache Redis.

embed("nettoyer poils chat") → knn(vec, k=20)
03

LLM Local

<500ms

Qwen 2.5 reformule les requetes ambigues, detecte le besoin fonctionnel, qualifie en max 3 questions.

qualify("cadeau maman") → {usages: [GIFT, BEAUTY], questions: [budget?]}
Reciprocal Rank Fusion

Les 3 etapes fusionnees par RRF — pertinence lexicale + semantique + intentionnelle.

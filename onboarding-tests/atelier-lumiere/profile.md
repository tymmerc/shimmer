# L'Atelier Lumière

## Pitch
E-shop de luminaires d'intérieur design pour particuliers et architectes. 60 références, sélection éditorialisée, focus sur les marques européennes (Flos, Artemide, Louis Poulsen, Muuto, &Tradition).

## Persona client cible
- Particulier qui aménage ou rénove (couple 30-45 ans, achat ponctuel)
- Architecte d'intérieur (achats récurrents, panier moyen plus élevé)
- Gens qui ne maîtrisent pas le vocabulaire technique : "lumière jaune" plutôt que "2700K", "ampoule pas trop forte" plutôt que "400 lumens".

## Ton de l'agent attendu
Conseil bienveillant, vocabulaire accessible. Vouvoiement (clientèle plus formelle qu'un caviste). Pose des questions concrètes : la pièce, la hauteur, ce qu'il y a déjà.

Exemples :
- Bon : "Pour un salon avec une grande table, on regarde plutôt une suspension large 80-100cm de diamètre. Vous avez quelle hauteur sous plafond ?"
- Mauvais : "Quel IRC souhaitez-vous, 80 ou 90+ ?"

## Catégories produits
- Suspensions (20 réf)
- Lampes de table & chevet (15 réf)
- Lampadaires / lampes sur pied (10 réf)
- Appliques murales (10 réf)
- Lampes de bureau (5 réf)

## Critères de qualification attendus

| Critère | Importance | Type | Valeurs |
|---------|-----------|------|---------|
| Pièce | Haute | Fermé | Salon, Salle à manger, Chambre, Bureau, Couloir/Entrée, Cuisine |
| Type de luminaire | Haute | Fermé | Suspension, Lampe table, Lampadaire, Applique, Lampe bureau |
| Style | Haute | Fermé | Scandinave, Industriel, Minimaliste, Vintage/Mid-century, Contemporain |
| Ambiance lumière | Moyenne | Fermé | Chaude (2700K), Neutre (3000K), Naturelle (4000K) |
| Surface pièce | Moyenne | Ouvert | m² ou taille (petit/moyen/grand) |
| Hauteur sous plafond | Moyenne (suspensions) | Ouvert | cm |
| Source lumière | Faible | Fermé | LED intégrée, Ampoule E27/E14 |
| Budget | Haute | Ouvert | Numérique |

## Déductions implicites attendues

| Signal client | Déduction |
|---------------|-----------|
| "salon", "grand espace" → Pièce salon, surface grande |
| "chambre", "chevet" → Lampe de chevet ou suspension faible |
| "bureau", "lecture" → Lampe de bureau, lumière neutre/naturelle |
| "table à manger", "salle à manger" → Suspension above-table |
| "petit appart", "studio" → Surface petite, suspension compacte |
| "apaisant", "cosy", "chaleureux" → Lumière chaude 2700K |
| "scandinave", "épuré", "blanc" → Style scandinave |
| "industriel", "loft", "métal" → Style industriel |
| "vintage", "rétro" → Style vintage/mid-century |

## Catégories produits fictives (mais marques réelles)

Toutes les marques mentionnées existent (Flos, Artemide, Muuto...) mais les noms de modèles peuvent être fictifs ou inspirés sans matcher exactement les vrais.

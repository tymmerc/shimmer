05 — Stack

Quatre couches. Une seule intention.

BOUTIQUE

SDK navigateur

<30kb gzip · IntersectionObserver · sendBeacon · Vanilla JS, framework-agnostic

sample
Shimmer.crossSell.renderInto('#xsell', { productId })
API

Express + TypeScript strict

Multi-tenant par Bearer key · validation Zod · rate-limit par store · OpenAPI 3.0.3

sample
POST /api/cross-sell/precompute
INTELLIGENCE

Claude / Ollama / Embeddings

Claude API en prod, fallback Ollama qwen2.5, embeddings multilingual-e5 ONNX

sample

DATA

Postgres + Redis + BullMQ

Prisma 6.4 · 20 tables multi-tenant · jobs précompute + reindex toutes les heures
